🧪 Mavjud testlar

Istalgan sondagi savollardan iborat oddiy testlar (A–F variantlar). Test kodi bilan yoki ro‘yxatdan tanlab ishlang. Test yaratish hamma uchun ochiq. Natija darhol ko‘rsatiladi.

➕ Oddiy test qo‘shish

Hamma test qo‘sha oladi (soatiga 3 ta, kuniga 5 tagacha). Testlar admin nazoratida: qoidabuzarlik bo‘lsa o‘chiriladi.

Muddat tugagach test avtomatik yakunlanadi va natijalar fayli botga yuboriladi. Istasangiz, muddatdan oldin qo‘lda ham yakunlay olasiz.

Savollar qog‘ozda, PDF yoki rasmda bo‘lsa — faqat to‘g‘ri javoblarni belgilang (10, 50, 100 yoki undan ko‘p — son cheklanmagan). Xohlasangiz, istalgan savolga ✏️ bilan matn ham qo‘shasiz.

Savol, variant matni va javobni birga joylang (A–F).

➕ Test yaratish

Siz yaratgan test admin nazoratida: qoidabuzarlik bo‘lsa o‘chiriladi va muallif bloklanadi. Reytingga faqat admin testlari hisoblanadi. Savollar matni kiritilmaydi — faqat to‘g‘ri javoblar kaliti belgilanadi. 45-savol esse bali esa talabgorning shu test mavzusida botda yozgan esse natijasidan olinadi.

Muddat tugagach test avtomatik yakunlanadi va natijalar fayli botga yuboriladi. Istasangiz, muddatdan oldin qo‘lda ham yakunlay olasiz.

Talabgor shu mavzuda botda esse yozadi. Umumiy natijaga aynan shu mavzudagi oxirgi esse bahosi qo‘shiladi. Boshqa mavzudagi esse hisobga olinmaydi.
